# Full-Stack Learning Platform

A full-stack learning platform built with NestJS, Neo4j, and Next.js featuring authentication, role management, course enrollments, and REST API architecture.

---

## Overview

This project consists of:

- Backend API built with NestJS and Neo4j
- Frontend application built with Next.js
- Graph-based database relationships
- Authentication and role management
- Course enrollment system

The platform demonstrates full-stack development, REST API architecture, graph databases, and scalable application structure.

## Running the Project

### Backend

```bash
cd backend
npm install
npm run start:dev
```

Runs on:

```bash
http://localhost:3000
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Runs on:

```bash
http://localhost:3001
```
